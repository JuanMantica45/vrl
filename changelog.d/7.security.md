Fixed nine panic and out-of-memory paths in the VRL runtime that were reachable from untrusted
event data or operator-authored programs: `find` with a negative or out-of-range `from`,
`format_number` on `±∞` or with a negative/huge `scale`, float arithmetic whose result is NaN
(`∞ * 0`, `∞ + -∞`, `∞ % ∞`), `parse_xml` on an element whose only child is a comment or
processing instruction, `starts_with` on invalid UTF-8, the `\}` string escape, and unbounded
array padding when assigning to a large array index (now capped at ±32768).
